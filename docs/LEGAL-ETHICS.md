# Legal and ethical boundaries

Study software that you own, are authorized to analyze, or may lawfully inspect. Prefer public documentation, licensed source, and authorized observable behavior. Verify the license and rights for each reused code segment and asset. No access-control bypass, credential extraction, unauthorized network capture, circumvention of subscription controls, proprietary code redistribution, or competitive multiplayer cheating.

Clean-room implementation is a technique, not an automatic guarantee of legality. Copyright, patents, contract terms, trade secrets, trademarks and anti-circumvention rules can still apply depending on jurisdiction. Get advice where needed. Source code and behavior inferred from a client do not reveal private server implementation.
