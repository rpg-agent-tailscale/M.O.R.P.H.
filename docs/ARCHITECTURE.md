# MORPH 1.0 architecture

`morph.py` is a small Python standard-library CLI. It creates four local Markdown templates: brief, soul, body and proof. Existing editors, development agents and test runners implement and validate the target capability. No new scheduler, inference provider, binary engine, or network service is installed.

Future integrations are optional and require evidence plus explicit authority. REA and Reversa remain independent external inspirations; no upstream code is vendored here.
