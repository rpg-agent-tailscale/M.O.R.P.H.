# Treasure Seekers MORPH pilot

**Goal:** deliver one visible improvement in the Maya/Marcus HTML character sheets with less rework by reusing existing Golden specs, approved assets, HTML and CSS.

**Frozen:** Do not change approved Page 1 or Page 2 composition. Page 2 header, layout, spacing, panels and art must be preserved. Demonstrative dice are not canonical.

1. Obtain the actual approved PAGE-1/PAGE-2 Golden specs and the current Maya/Marcus HTML and asset paths from the authorized private project. Never fabricate missing details.
2. Select just one visible/functional defect, e.g. an existing mismatch between a Golden panel and exported HTML.
3. Compare configuration, CSS extension, existing template reuse, compatible open-source libraries and new implementation. Prefer direct fixes to new frameworks.
4. Run one bounded proof, render Maya and Marcus, compare screenshots/print outputs with approved baseline, validate current behavior.
5. Capture measured time, acceptance criteria, remaining Improvement Debt and human review. Do not publish private images, characters, canonical assets or specifications into the MORPH public repository.
